# TIDAL: Two-Timescale Deadline- and Doppler-Aware Resource Allocation for Mission-Critical Underwater Acoustic Networks

This repository contains the discrete-event simulator, physical acoustic channel models, experiment drivers, and MILP oracle scripts for the research paper:

> **Two-Timescale Deadline- and Doppler-Aware Resource Allocation for Mission-Critical Underwater Acoustic Networks**  
> *Target Venue:* **npj Wireless Technology** (Nature Portfolio / Springer Nature)  
> *Author:* Degala Chenchupradeep (SRM University--AP)
